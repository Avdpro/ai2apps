# 用户自管网络访问

状态：2026-10-16 实现，App-Dev 激活；VPN/第三方隧道与真实手机组合仍需用户环境验收。

脱机帐号页提供“用户自管网络访问”。此功能不注册 Cloud 设备，不调用 Cloud 配对服务，不把手机变为 Desktop 管理员登录。模型调用和密钥仍由 Desktop 持有。

## 使用

1. 脱机模式直接进入帐号页；已登录设备可进入帐号 → 设备。
2. 选择接入方式：
   - VPN：监听地址填写本机 VPN 网卡 IP（支持 100.64.0.0/10 地址）；端口默认 57440。访问地址填写 `http://VPN-IP:57440`。手机须已接入同一 VPN。
   - 隧道：监听地址使用 `127.0.0.1`，端口默认 57440；访问地址填写自己的 HTTPS origin，例如 `https://desktop.example.com`。自行配置反向隧道到 `http://127.0.0.1:57440`，保留外部 Host，支持流式响应和文件上传。不要指向 Desktop 主服务的随机端口。
3. 保存并启用。点击生成配对二维码，手机扫码并填写设备名称。
4. 核对双方六位验证码，在 Desktop 点击“允许配对”。手机随后进入现有 Mobile 首页。
5. 在已配对手机列表撤销指定设备，或关闭整个入口。

二维码五分钟有效且仅可使用一次；手机会话八小时有效，仅保存在当前 Local 进程内。关闭/重配置入口、重启 Local 后需要重新扫码。监听配置会保存，下次启动重新绑定；VPN 网卡未就绪或端口占用时显示错误，可重新保存启用。

VPN 的 HTTP 访问依赖 VPN 本身提供网络加密。浏览器需要安全上下文的功能（例如麦克风）应使用 HTTPS 域名隧道接入。隧道供应商的上传大小、流式时长与带宽限制仍然适用。

## 边界

- 独立监听器只允许精确配置的 Host；写请求要求同一外部 Origin。不信任客户端传入的转发头。
- 手机先取得一次性扫码请求，再经 Desktop 独立批准，才能换取 HttpOnly/SameSite cookie。HTTPS 隧道 cookie 带 Secure。
- 手机请求移除所有外来 Cookie、Authorization 和 API key，以进程内授权对象进入现有 Mobile 白名单和 Studio 隔离网关。
- 不开放管理端、帐号设置、原始浏览器调试端口或任意 Desktop API。现有 Mobile 允许应用策略继续生效。原始 WebSocket 不开放；现有 HTTP/SSE/上传路径保留。
- 关闭或撤销会中断仍在输出的响应，不再允许新的操作。已经受理为持久后台任务的工作遵守原有任务取消机制，不会因退出手机自动删除。
- 默认关闭，不会自动创建或安装 VPN、隧道服务或第三方帐号。
