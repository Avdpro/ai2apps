范围为现有 AaAT 参数表单，不扩展到任意网页、用户内容或业务结果全文的机器翻译。

## Owner 覆盖

- Shopping Pro：购物历史、补货清单、补货建议、调整、购物车确认和礼物推荐；商品列表列标题、历史模式选项与确认按钮。
- Todo：搜索/读取/创建/项目定位/层级统计/子项查询；范围及状态枚举。
- Intelligence：频道、已存情报搜索/阅读、主题新闻、刷新和临时课题确认。
- Gallery、Knowledge：素材查找/读取，知识搜索/读取/保存；可见范围与内容类型。
- Voice：快速朗读、音频转写、Voice Design 参考转写、详细转写。
- Imagine：文生图、修图、合影、参考图创作、风格转换；动态模型 schema 的展示字段与质量选项。
- Search All、Web Reader：查询词、来源、模式、排序、页数/结果数/最大字符数、分身与保留页面选项。

翻译由 owner 提供，present_fields 只复制展示属性，key/value/schema 与权限不变。中文（含 zh-TW）用 zh，其他语言用 en。商品标题、模型名称、用户配置名称及输入原样保留。第三方翻译仍为推荐项而非注册门禁。JSON Schema 原始 title 和执行错误属于协议/诊断数据，未引入按业务身份猜译或运行时模型翻译。

ParameterForm / App handoff 的持久 prompt 采用英文兼容文本，ui_hints.prompt_labels 提供双语展示。待填表单的外层卡片标题、表单标题及共享身份标签也按当前语言显示；已有表单 GET 可从当前 owner 取回标题映射，不修改原确认参数。
