# Cloud 个人空间入口视觉改版

日期：2026-10-08。状态：待 Cloud 项目实施、部署；客户端未修改 Cloud 源码。

## 页面与范围

用户截图为 `coder.ai2apps.com/u/:ownerUserId` 登录后的入口页。已只读核对实现：Cloud 仓库 `src/spaces/page.ts` 的 `personalSpaceEntryPage(nonce)`，目前仅有 body 宽度、字体和表单基础样式。

本次只调整入口页面视觉和操作反馈，沿用现有用户固定 URL、登录、Owner 判定、公开空间和 handoff 流程。不要自动创建 Owner 会话，也不要把公开空间访问升级为私有应用权限。

## 视觉方案

采用 AI2Apps Mobile 一致的浅色界面，避免截图中大面积空白、默认按钮和没有层次的标题。

- 页面背景 `#f6f7f9`，可叠加极淡紫色径向渐变；文字 `#18181b`，辅助文字 `#71717a`。
- `min-height:100svh`，`box-sizing:border-box`；使用 safe-area-inset，左右至少 20px 留白。顶部品牌区距离安全区域 28px；主体卡片顶部间距使用 `clamp(28px,8svh,80px)`，避免大比例垂直留白。小屏、横屏和键盘弹出时页面正常滚动。
- 主体居中，最大宽度 440px，白底、24px 圆角、1px 浅灰边框、轻阴影；内边距移动端 24px，桌面 32px。桌面同样采用卡片，不拉伸成通栏。
- 品牌区使用 Cloud 已有 AI2Apps 标志资源和 AI2APPS 字标；不可依赖设备域名或新增第三方图片服务。没有合适资源时用字标，不虚构新 Logo。
- 标题“连接个人空间”：移动端 28px、字重 700、行高 1.25；辅助说明 15px、行高 1.65。
- 已确认登录且 Owner 入口可用时，在标题前显示小型绿色“已登录”状态标记；不能在身份检查完成前显示成功状态。
- Owner 可用状态说明：“选择进入你的应用，或访问公开空间。”
- “进入我的应用”为主按钮：黑色背景、白字、14px 圆角、至少 52px 高、16px 字号，整行可点，可附本地内联 SVG 箭头。下方小字“使用这台设备上的私有应用”。
- “访问公开空间”为次按钮：白底、灰色描边、深色字，相同触控高度；与主入口间距 12px，下方小字“查看设备已开放的内容”。辅助说明跟随对应按钮隐藏，不留空洞。
- 页脚仅保留低对比度说明“由 AI2Apps 安全连接”，不显示设备 UUID、租约时长或技术参数。

## 全状态与交互

保留现有 login/status/owner/visit/retry DOM id 和事件行为，并对所有状态使用同一卡片：

1. 检查身份、检查授权：中性状态图标和现有说明，不能闪现 Owner 操作。
2. 未登录：邮箱和密码使用可见 label，输入高度至少 48px、字号至少 16px，保留 autocomplete；主按钮“登录并连接”。不要 autofocus，避免 iPhone 自动弹键盘。
3. Owner 可用：主/次入口按上述层级展示。
4. 非 Owner：保留当前公开空间流程与拒绝私有入口行为。
5. 设备离线、尚未启用、需要更新、连接失败：同一卡片内显示易读说明及“重新连接”按钮；不要退化为裸文本或整个页面空白。
6. 点击进入/重试/提交时给对应按钮显示忙碌文案和状态，防止重复提交；失败后恢复可操作状态。不得改变 API 的授权语义。

必须保留 `[hidden]{display:none!important}`，防止按钮布局样式覆盖 hidden。`status` 保留 `role=status`，焦点轮廓明显，文本对比度满足 WCAG AA。动画仅轻量使用，遵从 prefers-reduced-motion。

## CSP 与上线约束

现有页面使用带 nonce 的 style 和 script。沿用现有 CSP nonce 机制；不得用 unsafe-inline 放宽安全策略。使用现有同源资源或允许的内联 SVG，不引入 CDN 字体/图标依赖。不要把账户凭证写入 URL、localStorage、日志或 DOM 数据属性。

## 验收

- iPhone Safari：375/390/430 CSS px 宽、横竖屏、键盘打开时无横向溢出，按钮易点、卡片可滚动。
- 桌面 Chrome：卡片宽度受限，品牌和主次按钮清晰。
- 未登录、Owner 登录、非 Owner、设备离线、接口失败均有一致外观；只在服务端认定可用时显示 Owner 按钮。
- 真实 Owner “进入我的应用”、公开空间、重试、登录提交与原流程一致，返回固定用户 URL 后可再次进入。
- CSP 无样式/图标阻止，无秘密信息输出；hidden 元素不可见且不可聚焦。
