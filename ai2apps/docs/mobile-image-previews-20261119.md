# Mobile Bot / Chat 图片预览（2026-11-19）

Mobile 信息流以前直接请求原图；历史 Chat 的部分图片还随内容响应以完整 base64 下发。现在内置 Bot / Chat 的图片附件、受保护生成图片及历史内嵌图片先显示压缩预览，用户点击图片查看或下载时才请求原图。

## 显示与原图

- 预览采用 JPEG，最长边不超过 960 像素，初始质量 58；必要时继续降质量或尺寸，输出不超过 160 KiB。
- 保持宽高比，校正 EXIF 方向，透明部分合成白底，不携带 EXIF；动图预览使用首帧。
- 原文件、下载内容、聊天持久化内容和模型输入保持原始数据。预览失败显示错误，不自动下载原图。
- 手机本次新选择的附件仍可在本地显示预览；这里优化的是从 Desktop 下载的信息流图片。外部网页图片和 Markdown 外链不由该接口代理或抓取。

## 所有权与传输

Bot 使用原 Bot / 主聊天 / 附件或制品读取授权，然后生成预览。Chat 生成制品和 Tool 结果仍验证所属 Run、成功记录输出、来源 App 及会话。签名网关将预览查询参数纳入原请求签名；没有开放任意路径或外部 URL 读取。

历史 Chat 内嵌图片在 Mobile 内容响应中投影为 thread / message / part / digest 绑定的受保护引用，原图 base64 不随历史列表下发。保存快照或提交模型请求前，由 Chat owner 从当前归属记录恢复原始图片，校验摘要与线程，限制恢复后的请求体积，拒绝跨账户、跨线程和过期引用。不写回压缩图，也不把压缩图交给模型。

预览只在 Desktop 本地生成：两线程解码，源文件最多 64 MiB、6400 万像素，文件预览缓存最多 128 项。授权在缓存读取前执行，缓存不缓存授权结论。响应 no-store；无 Cloud API 或 iOS 原生协议改动。
