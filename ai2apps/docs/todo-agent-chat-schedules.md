# Todo：定时 Agent Flow

桌面 Todo → System tasks → Agent 定时任务。输入目标，选择首次运行的本地时间、重复间隔（分钟）、模型隐私模式和是否推送结果。这里只创建用户自己的计划。计划由 Local 运行；Local 关机时不执行。

高级模型先从当前可见操作中选择候选，再读取候选的声明、效果和参数 schema，生成最多 12 步的有序数据流。草稿不启动任务；修改表单必须重新预览。确认提交的是服务端草稿 ID，不能由客户端改写模型、参数或 Provider；草稿一小时后过期。确认和写入系统定时器属于同一事务。可从 Scheduled 手动启动或停用。

运行时不重放 Chat 或重新规划。普通 AaAT 步骤使用确认时冻结的参数；只读通道可以通过受限路径引用前一步的输出。需要推理的步骤显式列出输入步骤、指令、模型档位、隐私配置和模型。模型无工具调用权。隐私不能被后续模型降级。能力、版本、可执行权限、参数契约和模型路由须仍然有效；不支持必须交互的操作，也不通过其他 Provider 绕过拒绝。工具派发仍经原 Gateway 和所属 App。操作回执不足以证明业务完成时，任务以部分完成结束并保留回执，不发成功通知。

通知只对已确认选择推送并已提交成功结果的任务进入原通知队列，按 task ID 去重，目标和接收者来自服务端。具体结果摘要可能显示于锁屏；未开启时仅在 Todo 历史查看。停用阻止后续步骤，不会撤销已执行的操作；处理中的系统任务可通过 Stop 停止。

验证区分：Python 测试使用真实临时数据库、调度器、Gateway 和素材读取，推理及推送传输为替身；Chrome UI 测试使用接口 fixture。不以此证明生产模型、Cloud 或 APNs 的可用性。
