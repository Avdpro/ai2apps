# ComApps · 传信：微信接入首版

传信（`ai2apps.comapps`）是桌面系统 App，可从 App 列表直接打开。已有传信
Package 的实例原地迁移到内置入口，Local 继续使用原来的微信绑定、CLI 配置和
微信 Bot 选择。App 列表使用带双向箭头的对话气泡图标，线条颜色随界面主题变化。

左栏管理已连接和正在配置的分身，右栏显示当前分身的操作区。首次打开且没有连接
时，从「添加分身」开始。已有 iLink 绑定和 CLI 配置会自动显示。当前每种微信连接
各保留一个分身。Telegram、WhatsApp、iMessage、Messenger、LINE 和 KakaoTalk
在添加菜单中标记为暂不可用。

iLink 面板显示绑定状态、上次成功检查时间和最近发送结果。刷新读取 Local 已知状态。
自动回复使用开关。退出连接清除本机 iLink 凭据和近期收发预览，保留分身供重新扫码。
最近收发显示绑定会话在 Local 记录的最新 12 条，包含文字预览、附件类型和发送结果。

后续 AaAT 按分身模式定义。Agent 对话模式围绕已绑定用户的单一微信会话与 Bot
状态。IM 代理模式按已绑定账号提供会话、好友、群和消息查询。能力声明与归属校验
由传信维护，并与界面共用连接服务和权限检查。当前界面沿用现有连接能力。

- 默认 iLink：二维码、扫码状态及验证码、绑定、手动收取一批绑定用户的文本、
  明确确认后回复。绑定、游标、有限的去重记录和最新消息保存在按安装与用户隔离
  的 SecretBackend。发出请求前消耗回复引用，超时后不重试。接口受理不等同送达。
- 高级 WeChat-CLI：显式输入本机的 `wechat-agent` 绝对路径；Shell 展示路径并确认后，
  Local 检查文件权限、记录摘要、列出分身。绑定要求已有运行且登录的分身，固定
  profile 和当前数据库 namespace。读取前后检查身份并将操作固定到观测的 PID。
  首版只读会话、好友、群目录和有限的本地消息；不执行发送或操作全局队列。
- 内置界面运行在独立来源的沙箱中。Shell 按当前 App、iframe、实例、mount
  token 和操作白名单转发；Local 再校验 loopback、同源、有效桌面 Cookie、实例归属
  及系统 App 来源。CLI 操作要求 Core/Owner。对外回复目标由已绑定的会话固定，
  页面不能指定对方 ID，也不拿到任何 iLink 凭据。

协议参考：腾讯 openclaw-weixin，iLink 2.4.10，参考代码快照
`874637a0dbc24050f72d1385add4fc6170a2d726`；本机微信 CLI v1 参考
`~/.codex/skills/wechat-cli/references/cli-reference.md` 和 `scheduling.md`。

当前是连接验收切片：不自动触发 AI2Apps Agent、不后台轮询、不承诺主动推送，
同一用户保存一个 iLink 绑定与一个 CLI 分身。真实验收在隔离环境中使用测试微信账号：
用手机扫码，在机器人会话发一条文本，检查 Local 收取内容并由用户确认回复，
在手机端检查送达；再填入明确选定的 CLI 路径，绑定已登录分身并查会话。
正式 Package 签名、干净 Test 安装和后续发布按 Package 发布手册办理。

## iLink 自动回复

手动回复已由用户确认送达手机。现有绑定可以直接开启「Bot 自动回复」，无需再次扫码。
Local 在后台按顺序收取绑定用户的私聊文本，并用该用户的默认 AI2Apps Bot、已有会话和
模型配置生成回复。关闭传信窗口不关闭渠道；可用开关暂停或解除绑定。微信输入不充当
App/工具审批。Bot 如果创建后台任务，首版回传当前短回合的排队提示，任务结果和审批
继续在 AI2Apps 中处理。

适配器不修改 AaAT 路由、声明或共享执行策略。入站游标与待处理消息一并保存；已接纳的
Bot 回合按消息身份幂等恢复。回复在发送前持久登记，超时或重启后不会重发未知结果。
仅发送到原绑定用户，并使用同一条入站消息的上下文。首版仅处理文本。

验收：39 项定向测试通过，其中新增用例通过真实 SQLite、Bot 会话与 AgentRuntime 跑通
回复和发送超时去重；微信接口和模型为测试替身。固定 App-Dev 确认空闲后由自身 Helper
重启；Local PID 8680、端口 57240，运行日志确认当前源码导入、返回的 Shell JS 与源码一致。
在真实绑定上已开启自动回复，等待手机发来一条新的验收消息。

iLink 自动发送的 Bot 回复统一带 `[🤖AI2Apps]: ` 标签。标签只加在发往微信的文本上，
并计入回复长度；AI2Apps 内保存的原始回复和手动回复保持原样。

## 微信 Access 菜单

仅跟踪从当前微信绑定发起、由默认 Bot 创建的原任务。普通 App/Mini-App Access 等待时，
微信显示任务、目标、操作和权限范围；第一张菜单可回复 1（允许）、2（拒绝）、3（详情），
也可带编号（A1/A2/A3）。后续菜单始终要求编号，避免迟到的数字落到另一项申请。只有
接口已受理、发送时间早于选择、原 Interaction 未过期且授权快照一致的菜单才接受选择。
数字选择不进入模型。首次允许会持续授予此 Bot 普通 App 访问；已有权限时仅继续本次。
付款、删除、发送、显式确认及其他需要人工输入的交互仍回原 AI2Apps Bot 界面处理。

原 Messager App Access owner 复核并恢复原 Run，拒绝提交给原 Interaction。Local 发送
原任务的文字结果及下节支持的附件。iLink 会话失效时，用户可在 AI2Apps 查看原审批
和结果。对发送结果未知的通知或回复不重发。关闭自动回复后停止追踪渠道任务，
不会取消用户已发起的 Bot 任务。

Access 菜单验收：62 项定向测试通过，使用真实 Bot 短回合、Todo 任务、Agent Run 和
Interaction；微信、模型及实际工具使用测试替身。覆盖授权后继续原 Run、拒绝、
详情、权限变化后旧编号失效、迟到数字、重复消息、特殊确认与文字结果回传。
固定 App-Dev 空闲检查通过后由自身 Helper 重启，PID 10233、端口 59232；健康
检查通过，运行中 ComApps 模块路径和实际提供的 Shell 资源均匹配当前 checkout。
原有绑定仍启用；未替用户在真实微信发起或批准访问。

## 微信字母菜单

开启 iLink 自动回复后，单独发送小写 `b` 查看当前账号可通过微信对话的 Bot。
菜单列出普通 Bot 和 Flash-Bot。ASC-Bot 在 AI2Apps 中打开对应 App。
每页显示 20 个，编号跨页递增。发送 `bp2`、`bp3` 翻页，发送 `b1`、`b12` 切换
到已显示的对应 Bot。列表变动导致编号指向不同 Bot 时，需重新查看菜单。
切换只影响此微信绑定后续的消息，原任务和 Access 审批仍归原 Bot。Access 带字母
的编号请按菜单显示的大写格式回复（如 `B2`）。

单独发送小写 `p`，相当于在 AI2Apps 对当前对话 Bot 点击一次 Poke。Bot 按现有
任务状态回应，待处理附件可继续用于下一条文字指令。Flash-Bot 请直接发送工作流
输入。微信沿用 Messager 的输入校验和任务执行，结果返回原微信会话。需要审阅工作流
草案或补充确认时，微信会提示打开 AI2Apps 中的对应 Bot。

## iLink Bot 附件

开启自动回复后，绑定用户可发送 JPEG、PNG 图片或有可提取文字的 PDF。图片每个至多
8 MiB，PDF 每个至多 25 MiB。连续发送附件时暂存最近两个，收到回执后 15 分钟内可发
一条文字指令，Bot 将附件和指令一起交给任务。Access 数字选择单独处理。

Local 从微信 CDN 下载并解密，验证后登记到默认 Bot 会话。图片走现有视觉模型输入，
PDF 走现有文档解析和有界文字摘录。扫描 PDF 暂无 OCR。任务完成后，原结果回执中登记的
JPEG、PNG 和 PDF 产物可加密上传微信 CDN，并以微信原生图片或文件回到发起会话。
每个任务最多回传两个附件，其余产物可在 AI2Apps 查看。

定向验收覆盖 PNG、JPEG、PDF 的加解密、先附件后指令、Bot 读取附件、原 Access 菜单、
任务产物回传及附件字节一致性。测试使用真实 Local 会话、任务和产物仓库，微信/CDN、
模型与工具输出使用夹具。固定 App-Dev 的 Local（PID 12014，端口 60713）已在空闲时
重启，运行中模块和实际提供的 Shell 资源均来自当前 checkout。用户已确认微信图片
往返实测通过。PDF 手机端往返待验收。

## 代理模式 Worker 工作台

左栏切换分身，中栏显示 App 连接与 Worker 列表，右栏编辑所选 Worker。已绑定的
连接默认折叠。可从最近会话、好友和群聊选择目标。名单、Worker 与群发草稿由
Local 按安装、使用者、CLI profile 和数据库 namespace 保存，改绑后切换到相应工作区。

监听 Worker 绑定一个会话或新用户请求，可挂多项 Work。模板预填触发条件和响应要求，
每项可单独保存启用状态，工作日志区当前为空。群发 Worker 可合并保存的会话名单，
保存文字、图片 URL、视频 URL、链接和期望的发送间隔。工作台当前保存配置；
消息监听、调度、执行日志与真实发送待接入，群发内容不会进入 CLI 共用发送队列。

会话选择支持按昵称、备注、群名或微信号搜索。Local 合并微信 CLI 可读的会话、好友
与群聊后再筛选和限量，结果按匹配程度排列。界面分别提示匹配结果太多和微信目录不完整。
