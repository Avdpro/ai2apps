# Bot 对话剪裁与即时 Poke

Messager 拥有剪裁业务；Desktop 同源入口和 Mobile owner mount 入口复用同一 owner 服务。确认预览绑定 actor、Bot、主对话、Bot 消息位置、后续消息及独占素材清单；新增消息或素材使用范围变化使旧确认失效。保留选中回复，移除之后的对话正文，不修改 Access、记忆、Run、Task、计划或执行工作区。任务仍可能产生新的消息。

剪裁保留无正文的消息序号/幂等占位，防止迟到回调重建已删除消息；通用消息存储只识别退休记录，不识别 Bot 或业务能力。App Chat 分页输出会话 revision，桌面和手机发现变化后重新读取，避免其它页面残留旧历史。新输入序号继续增长。

输入/输出只按当前 Session 的真实 attachment/artifact 身份回收。保留消息、资源记忆或活动任务仍使用的材料不回收；其它会话、Gallery 和任务工作区的独立副本不变。文件引用只删除应用自己的引用清单，不能删除用户磁盘原文件。底层 blob 被其它附件、产物、有效资源句柄或待导出操作共享时保留。清理失败由持久回执重试，不再扩大剪裁范围。

Poke 在点击时立即置灰并显示用户气泡，以原 request_id 与持久消息去重；收到对应持久消息后恢复按钮，不能只依据 POST 返回恢复。Poke 自己的确认等待不锁住普通文字输入。失败移除临时气泡并复用请求 ID。审批、权限捕获和运行过程没有变化。Bot 名称提示以头像右缘定位，分组名也支持提示；栏宽改变时清除旧提示。

验证：最终 owner 6 项回归通过，覆盖精确位置/外部 actor/Bot 隔离、陈旧确认、独占文件回收、共享 blob/活动输入、内容去重占位、清理失败重试时新增文件使用及已排队对话继续完成。消息身份/分页/Mobile 组合 23 项通过。桌面/390px 对话框、Poke 的 POST 与消息分离延迟、头像边缘提示均有浏览器夹具；手机完整当前模板也通过实际点击、持久回复去重及取消剪裁确认。测试中的模型/业务效果为夹具，不代表 Cloud/真机 Mobile 验收。
