# Harness 指定目录导入

`host.directory.list(root,path?,offset?,limit?)` 只列举用户明确指定目录中的文件信息；
`host.directory.import(root,files[])` 只把选中的相对文件路径复制为当前执行 Session 的
产物，返回真实 artifact ID、类型、文件名及下载地址。兼容的 Mini-App 直接消费这些 ID。
源文件不修改，命令进程仍只能访问自己的工作区，未扩大为整个主机的任意命令权限。

Harness 复用普通 App Access/Provider 审核。额外的目录范围来自 App Chat owner 对
当前任务原始用户请求的投影，不从模型参数、文件正文、助手历史或摘要取得授权。
目前支持显式绝对路径、`~/` 路径，以及桌面/文稿/下载中明确命名的子目录。
没有可验证范围时拒绝读取，要求用户明确目标；不推断整个用户目录，不扫描磁盘找相似名。
任务续接只保留同一逻辑任务中已验证的直接用户请求；模型生成委派默认没有新增本机目录权。

macOS 对根目录使用 O_NOFOLLOW_ANY，原子禁止路径中所有符号链接；其它平台逐层打开。
子目录和源文件按描述符打开，禁止符号链接、上级跳转、特殊文件和路径替换逃逸。
每文件64 MiB、每批64文件/256 MiB。复制期间源文件变化则停止；全部源快照完成后才
创建产物，同内容/名称导入复用已有产物。跨用户、跨 Session、撤销及取消仍按宿主复核。
不允许由返回数据提高权限，也没有通用 Agent 业务分支或效果未知的绕过路径。

Bot 命名由 Messager owner 负责：title/step_label 只描述工作与目标，排队状态独立显示；
保存前清除模型产生的调度前缀，保留“排队算法”等实际主题名称。
