# 搜索读取的时间预算、补位与无人值守策略

## 原则及范围

共享 Search All/Web Reader 调用优先完成读取，不因任何网页交互要求用户协助，不让单个网页的人机交互挂住搜索父流程。以下行为同时用于文章 Mini-Chat 的 Desktop/Mobile；仍复用共享后台 Browser Task、BiDi SDK、签名 owner 程序、TaskTree 取消和引用校验，不建立另一套浏览器执行协议。

## 时间和候选页

- 每个搜索来源、每页 Web Reader 调用最多等10秒，包括地址解析、队列等待和浏览器执行。Google 重定向解析在剩余总预算内最多等1.5秒；失败单独记录，不丢弃同组已取得的其他地址。浏览器任务超时后走原 TaskTree 取消；网络断开的未知效果不自动重放。清理可能在后台继续，不阻塞父搜索的其他读取。
- 普通 read_page 的 SDK 同样设10秒上限。已有分阶段/媒体专用工作流保持其自身声明，不将视频字幕等误当成普通网页读取。
- 新的文章快速搜索一次取得最多8个候选，先读3篇；失败后按同一次、已确认的结果列表补位。普通 Search All 先读5篇。既有 read:N 动作键和已成功正文保持不变；总读取尝试最多9页，候选不足即结束，不为了补位发第二次搜索。旧的3候选确认回执继续兼容。
- 每次读取有独立的成功/失败记录；摘要仅使用已读原文，不能以搜索片段代替正文，不能制造来源或放宽引用ID校验。

## Blocker

1. 先沿用有界的确定性关闭/拒绝非必要Cookie处理，并在实际原生点击后重新检查。
2. 非实质访问限制遮挡内容时，读取已加载且具有渲染盒的 article/main 段落；不移除访问控制、不解锁隐藏内容、不读取脚本中的隐藏正文，也不换HTTP通道。结果标记 loaded-dom-under-overlay 和提示。
3. 无可读正文且是普通未知推广时，仅在当前Task允许视觉的情况下按 owner execution_policy 进行最多一轮、4秒内的视觉辅助。模型只能从当前弹层中观察到的非提交/非表单关闭候选 ref 选择；使用既有截图、标注复核、原生输入、DOM再检查。不能接受同意、订阅、关注、登录、提交或跳转。未确认的点击不再次重放。
4. 视觉不可用、超时或不能确认关闭，则该页失败并补位。未知非必要 waiting_input 子任务通过标准取消终止，不要求用户处理。
5. 登录、验证码、隐私/法律同意等所有人工事项，在搜索适配器内立即记为 read_requires_interaction，requires_user=false、help_url为空；不转发人工等待进度或协助入口，通过标准TaskTree取消对应子任务，然后从已确认结果池补位。付费墙和其他明确restricted状态同样失败并跳过，不绕过访问限制。所有候选均失败时正常结束为“无可读来源”，不等待用户操作。

Web Reader article owner 程序声明 visual_locating=true、visual_review=on_recovery、readback=true；共享执行器不覆盖 owner 政策，未声明视觉能力/缺少可用视觉模型则安全跳过。现有 General Agent 无任何情报中心或Provider身份分支，检查策略未改。

## 与交互式浏览器的边界

共享 wait_task 的 stop_on_assistance=True 分支由搜索与搜索读取调用；所有人工等待均失败并取消，无类别例外。内部浏览器动作的等待（requires_user=false）仍可继续至正常完成。默认交互式观察模式保持原协助行为，独立浏览器任务仍可请求用户处理访问要求。

文章Mini-Chat不再渲染或累积搜索协助引用，已保存的旧协助记录也不显示。动作结束时清除旧协助字段，避免历史缓存重新出现求助入口。既有Shell任务导航和独立浏览器的任务归属检查保持不变。

## 2026-10-24 无人工协助策略修正

原策略仍对登录、验证码等保留协助，这不符合用户最终要求。本次取消搜索链路的所有类别例外；对每种人工等待覆盖取消与无进度泄漏，并验证默认交互任务仍保留协助。Desktop/Mobile共享同一适配器与Mini-Chat，旧记录均不得渲染求助链接。最终测试和启用结果见发布账本 NXR-UNATTENDED-SEARCH-READING-20261024。

## 快速搜索关闭视觉（2026-10-24）

视觉辅助独立于人工协助和超时，是现有Task execution_policy参数。默认允许视觉定位、恢复时复核；快速搜索在来源查询和每个结果页读取时明确传 visual_locating=false、visual_review=off，保留readback。确认后的mode持久化并传到读取步骤，不能因恢复或切换Desktop/Mobile而丢失。快速模式因此不会在10秒总预算内发起视觉调用。普通读取、购物车等原owner策略保持不变；该参数不代表授予额外操作权限。完整参数契约见webagent-visual-control-recovery.md。


## Task 正式参数升级（2026-10-24）

无人值守不再只由适配器事后拦截：Task 明确传 allow_user_intervention=false，专用执行器在创建协助/审批 Interaction 前拒绝。来源查询与页面读取将10秒总时限写入正式 timeout_seconds，入队截止时间持久化，runner在页面准备与动作执行时使用剩余预算。旧适配器10秒上限与取消观察继续作为外层保护。快速模式额外明确关闭视觉；恢复预算/次数默认null，仅保留已有约束，没有擅自关闭非视觉恢复。完整合同和兼容语义见 task-execution-policy-20261024.md。
