# 匿名访客持续浏览：Cloud / Local 会话续租需求

状态：用户已批准改进；交由 Cloud 项目实现并冻结接口。当前生产仍是 anonymous-v1 的 120 秒访问，不得宣称已支持续租。本仓库按 Cloud 变更边界不修改 Cloud 代码。

## 要解决的问题
现在一次性交接兑换到的断言 exp 同时成为 Local Cookie、会话表和页面清空的截止时间。访客即使正在看内容，120 秒后也被中断。不能只增大前端定时器、Cookie max-age 或 Local 缓存寿命；那会越过 Cloud 授权。

目标：交接仍短时单次；兑换后建立独立匿名访客会话，由短租约持续验证。正常浏览超过两分钟不会跳页、清空内容或重载 App。无需 AI2Apps 账户，不产生 Local principal。

## 建议的产品时限（请在生产回执明确最终值）
- 一次性交接码：保留 60 秒，一次兑换。
- 匿名会话：绝对上限 8 小时；闲置上限 30 分钟。
- 每次签名访问租约：最长 120 秒，Local 在剩余 60 秒时合并续租；不是重新创建会话/交接码。
- 前台可见页面的阅读心跳视为浏览活动，不要求访客不断点击。活动上报最多每 60 秒一次；后台标签页停止活动上报。单纯后台服务端轮询、资源缓存刷新不延长闲置期限。
- 切回前台先重新验证，仍处于 8 小时/30 分钟窗口内时原会话可继续获取新租约；不能因为后台错过短租约就强制重新扫码。
- 到绝对/闲置上限，保留固定用户 URL 的“重新进入空间”按钮，不自动循环创建会话。关闭、撤销、设备解绑或映射变化不允许续租复活。

## Cloud 合同要求
采用独立且有版本标识的匿名会话/租约合同，与 anonymous-v1、旧账户访客和 Owner Home 同时兼容。以下是需求，不是客户端已经可以调用的端点：请提供最终精确 method/path、请求和响应 schema、错误码、签名 schema 及 Edge 清单。

1. 交接兑换建立 Cloud 持有的匿名 session，响应 session ID、创建时间、绝对/闲置截止、短期签名 lease、固定 spaceUrl，以及如有必要的服务端续租证明。
2. 提供 Device-authenticated 的续租/活动/撤销能力；仅凭 session ID 不能续租别人的会话，必须绑定原 Device、installation、Owner、匿名会话及作用域。长期续租证明不进入 URL、不交给浏览器、不记录日志。
3. 精确签名绑定 issuer/audience/protocol/scope/anonymous mode、session/jti、Owner/device/installation、access/mapping/capability/space/published 代次、iat/nbf/lease exp 和会话绝对/闲置截止。Local 验证时间与每一个绑定，禁止将旧 v1 token 当新租约。
4. 限制每设备活跃会话、每会话续租频率及匿名创建频率。续租使用已有会话，不消耗“新建交接/断言”配额；多标签页/并行资源不得造成续租风暴。限流返回 Retry-After，不能用无限重试或新建匿名身份绕过。
5. 同一续租请求必须有明确重试/幂等语义，迟到的旧租约不得覆盖新版本或延长已撤销会话。
6. 开关关闭、撤回发布、设备停用/解绑、访问 epoch 改变及 Owner 主设备映射改变都应撤销相关会话。关闭 Local 仍先立即拒绝访问并递增 epoch，再同步 Cloud；Cloud 失败不回滚本地关闭。
7. 发布内容时 Local 仍推进 revision 并拒绝旧快照/资源。Cloud 可允许续租更新同一匿名会话至新的发布版本，但不能混用新旧代次；若本期无法做到，请明确是否要求访客重新进入。第一目标是杜绝固定两分钟中断，不弱化现有发布撤销规则。
8. 保持 published=true + publishedAppCount=0 的文字、链接、空发布页正常可访问。访客开关独立于 Owner Home；无账户 Cookie 访问仍正常。

## Local 落地清单（正式合同回执后实施）
- 将现在 sessions 中的断言拆分为会话身份、租约截止、绝对/闲置截止；租约到期不立刻删除仍可续租的会话身份，但拒绝用过期租约提供内容。
- 服务端 opaque Cookie 可覆盖会话有效期（不得超过绝对截止），不直接存 JWT；每个 bootstrap/资源请求仍须有效租约和当前 Local 开关/快照验证。
- 每会话 single-flight 续租，近到期提前更新；最终放行前重查 Local epoch、安装绑定、published revision，防止“关闭与续租竞态”。
- v1 Cookie 保持原 120 秒语义，不在本地静默升级。新会话通过新合同建立。
- bootstrap 返回 leaseExpiresAt / absoluteExpiresAt / idleExpiresAt（最终字段由合同确定）。浏览器持续使用同一页面和 App frame，续租成功不触发重绘、history 跳转或清空。
- 后台暂停活动心跳，pageshow/visibilitychange 恢复时先验证。网络短暂中断显示“连接恢复中”，不误称已登出；有效租约到期必须暂停受保护资源，不离线延长。
- 401/撤销/关闭为终止；429/5xx/断网区分处理，受限退避且受截止时间约束；不存在自动调用公共 handoff 循环续命的路径。
- 关闭后服务端立即拒绝，前台最多在一次状态轮询内清空（建议不超过 10 秒）；已送达的公开文字/图片无法从访客设备远程收回，应准确表述撤销边界。
- Edge 仅增加完成该合同必需的精确访客路由；继续拒绝私有 App、管理、文件、模型、Owner/Package Bridge，不放宽 sandbox/CSP。

## 验收矩阵及交付
- 空 Cookie 未登录浏览器连续前台阅读至少 10 分钟，不点击也不中断；记录多次续租、同一 session、无新 handoff，App frame 不重载。
- 前后台切换超过 120 秒且未闲置 30 分钟，能恢复；超过闲置/绝对上限后准确终止，不自动创建新会话。
- 真实 Chrome / iPhone Safari：主页、嵌入 sandbox App、后台恢复、Cookie 与资源加载正常；不得用单元测试替代。
- 关闭/重开、撤回/重发、映射和 access epoch 变化、跨设备/Owner、篡改/重放、旧租约晚到、并发续租/关闭竞态全部验证。
- 模拟 Cloud 超时、429、5xx、断网：无无限重试、无过期租约放行、无重复创建；恢复在授权窗口内继续。
- 旧 anonymous-v1、账户访客及 Owner 8 小时流程回归通过。
- Cloud 回执提供最终 API/JWT/错误码/配额/Edge 协议后，Local 接入、指定 Dev 重启联调；无需更改用户已经发布的内容或重新开启访客开关。实现和验收状态分别记录。
