# WebAgent 模型 JSON 修复

规划（含非编译浏览器步骤）、Agent 编译、Review 修改、结果展示和 durable
`ai.extract` / `ai.classify` / `ai.transform` 使用 `agents/json_output.py` 的统一策略。

- 严格解析 JSON；可去除完整 Markdown 代码围栏，不猜测/改写值，不执行模型代码。
- 解析错误与结构/编译校验错误共用两次修复预算：初次调用加最多两次修复。
- 保留原任务、Schema、模型及参数，附上失败输出（最多 16000 字符）和校验错误
  （最多 2000 字符），要求返回完整修正结果。沿用已有探索模型升级设置。
- 模型调用/HTTP 失败不消耗格式修复重试；预算耗尽返回现有错误或走失败跳转。
- 修复只请求模型，不重放点击、上传、发布等浏览器动作。
- Durable 修复使用 `<原 call_id>:json-repair:<次数>`，恢复时重用持久化结果；
  步骤证据记录 `json_repairs`。日志记录模型、阶段、次数和错误类型，不打印输出全文。

定向测试包含格式错误后接结构错误、三类 AI 步骤、持久化恢复、预算耗尽、
编译/Review/探索 API，以及原有基础能力、条件跳转和子 Agent 调用回归。
测试使用故意返回坏 JSON 的模型替身，不代表所有实际模型均已实机验收。
