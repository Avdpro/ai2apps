# Bot/General 工具历史载荷 Context 优化

日期：2026-11-08。实现位于通用 General Agent，不按 Bot、业务 Tool、App 或 Provider 名称分支。

## 本轮行为

- 保留完整调用顺序及错误，不做“最近三次”滑动窗口，不按历史年龄重写消息。
- 只投影已完成/失败调用的历史参数；当前真实调用和持久记录不变。历史参数必须与该 Tool input 完全一致，否则保持原文。
- 输入中超过 8 KiB 的字符串、省略超过 256 字节的 DataURL，以字段级引用替代；保留精确字段路径、哈希、字符/字节长度、少量预览、原文读取入口。短值、素材 ID 及其关系不变。
- 结果中的 DataURL 同样引用化；其它超大文本和列表继续现有整结果分页。owner 的有界结果 Context/结构化证据继续保留，不通过共享层猜测业务摘要。
- agent.read_tool_result 增加 source 与 JSON Pointer path；按当前 Run/Session 归属读取原始 input 或 completed output，字符串片段不加 JSON 转义。没有跨 Run 扫描或授权扩展。
- 原有全文 JSON 分页序列化与偏移保持不变，防止旧回执的 read offset 失准。重复读取去重加入 source/path，避免输入和输出碰巧相同时错误去重。
- 无原文 reader 时不省略；投影是历史数据，不可以作为新调用参数直接重放。需要完整值时模型应读取原文，媒体感知继续已有素材输入机制。

## 缓存与续接

首次进入下一轮时确定性投影，后续不随轮数变化。追加模型步骤的测试验证旧 transcript 前缀不变。任务产物、短参数、错误和调用对应关系保留；原始记录可按字段读回。不引入额外模型总结调用，也不压缩用户原始请求或更改执行权限。

上线后旧执行历史在第一次使用新投影时会改变一次；新执行阶段保持稳定。尚未处理重复的完整声明语义去重、任务跨 Run 历史摘要和检查点阈值优化。

## 验证与范围

使用两个任意 Provider 标识、真实 General transcript/原文 reader，验证输入输出原文读回、Unicode 偏移、嵌套/转义路径、失败输入、跨 Session 拒绝、去重隔离、pending 与实际参数不变、后续轮次前缀稳定。外部业务和模型为夹具；没有重新发送用户历史或付费生成素材。

合成大载荷输入 127,076 字节，投影后 2,590 字节，减少 97.96%。这是刻意包含 100KB DataURL 的字节对比，不是实际 Bot Token、计费或缓存命中率承诺。收据：acceptance/tool-payload-context-20261108/fixture-size.json。
