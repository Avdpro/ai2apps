# Bot M1/M2 核心落地记录

日期：2026-11-04。对应 [完整计划](bot-memory-and-history-plan-v1.md)。本阶段实现 M1 历史查询和 M2 结构化记忆核心；不提前开放自动提取和共享 lane 里的记忆维护任务。

## M1：历史独立于近期窗口

`messager/history.py` 由 Messager owner 管理 Task-Session、实际执行步骤、用户指令、结果摘要和产物索引。查询不受近期 20 项窗口限制；返回分页、实际执行状态、索引覆盖范围和资源是否仍可用。索引每次最多处理 1000 个任务，调用方必须继续游标后才能断言更早历史不存在。中文使用字面子串匹配，FTS5 用于精确词排序。

三个 AaAT：`messager.history.search`、`messager.history.get`、`messager.history.attach`。通过执行 Session 的 owner/actor/Bot 确定范围，不接受其他 Bot ID、文件路径或任意 URL；仍走已有发现、声明和授权检查。attach 仅复制所选确切任务的可用输出 Artifact，重复调用复用已复制产物。它不执行历史任务，不恢复旧权限。历史文本为不可信数据。

当前记录真实步骤和输入附件标识，未构造编辑谱系，不能把前后两张图片的时间顺序当成编辑关系。历史输入附件的自动带回、前台如何主动检索历史，以及完整编辑谱系后续补齐。对话清理后的归档 Session 不在普通历史检索范围内；独立归档 Task 可通过显式 archived 查询读取。

## M2：可追踪、可撤销的记忆

`messager/memory_records.py` 在原有便签之上增加字段、证据和变更表。字段用 subject/predicate/variant 定位，支持 fact、preference、resource。默认同字段同值合并来源；图片按内容哈希去重。不同用途通过 variant 分开，不能自动把新照片设成默认。不同值必须显式 replace，并携带当前 revision；不会静默覆盖旧称谓或资源。

资源保存使用工作区 Artifact 身份。外部文件选择器产生的引用先保留实际文件内容到工作区，不把临时 URL/路径当长期身份。长期记忆未清理时，其显式保留的素材可在原对话归档后读取；读取接口仍检查同一 actor/Bot、有效记忆和实际素材状态。

便签更新、字段、证据和变更回执在同一 SQLite 事务中提交。失败一起回滚。通知在提交后按稳定幂等键投影到当前对话；恢复只补发已提交的提示，不重新调用模型或业务工具。已清除/归档的对话和已被后续版本替代的延迟提示不会补发。原有对话确认保存记忆的回执直接关联版本记录，避免双重提示。

撤销只在当前版本仍等于该变更版本时生效。存在后续修改时拒绝旧按钮覆盖；撤销合并只移除本次新增证据，保留独立来源。撤销不修改 App Access，不启动或撤回业务 Task。稳定请求 ID 防止重复提交。

## 界面与接口

右侧“记忆”增加“查看记忆版本与撤销”和“查询历史任务与产物”。版本页支持分页，详情展示变更前后、字段用途、来源和撤销状态。新记忆生效消息附有“查看记忆 / 撤销”；按钮按数据库回执绑定实际消息 ID，不从模型文本识别操作。原图片展示组件保持原实现。

新增 owner API：GET history、history/{task_id}、memory-changes、memory-changes/{change_id}；POST memory-records、memory-changes/{change_id}/undo；GET memory-records/{memory_id}/resource。所有接口复用 Bot 访问检查，写接口还要求可信宿主来源。资源响应使用固定 Artifact 路径，nosniff/no-store，只有安全图片类型可 inline。

## 边界与下一阶段

本阶段没有自动扫描每条聊天，没有新模型调用，也没有自动把照片声明为“本人”。现有明确保存入口和宿主结构化 API 可使用新核心。旧便签继续工作，下次修改产生版本，不对历史便签执行批量语义迁移。

M2 的维护 Task 优先级、批处理、公平调度和候选待处理/取消尚未接入；M3 的自动候选、语义合并、相关性召回和资源自动注入也未启用。接入前必须与 Bot 通信 Session 的共享 reentry/lane 约定对齐，并加入来源遗忘水位，确保清理后不会由后台提炼复活。当前只保证版本冲突和延迟通知恢复的防护，不声称具备自动写入场景的完整遗忘机制。

## 验证

使用真实 SQLite、工作区和 ToolGateway，模型及媒体字节为夹具；不调用付费生图或修改用户真实记忆。核心测试覆盖超过 20 项查询、中文和字面匹配、同 Bot 隔离、资源失效、照片持久化、来源合并、称谓替换、旧版本撤销拒绝、事务回滚、重复通知恢复、确认回执映射、历史产物复制幂等，以及资源 API 隔离。界面测试覆盖消息 ID 绑定、销毁后不回写、撤销重复点击。
