# Video Composer

Arrange existing video and audio clips on a timeline and render a composition.

## How to use

1. Give the project a useful title and add media clips to suitable tracks.
2. Set clip timing, track order, muting, and other timeline options in the workspace.
3. Preview the composition and render when the timeline is ready.

Chat can rename the current project and start rendering; detailed clip editing remains available in the visual timeline.
