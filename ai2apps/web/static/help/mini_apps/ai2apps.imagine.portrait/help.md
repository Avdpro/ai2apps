# Portrait / 人像摄影棚

Upload a clear photo of one person. Choose Photo-ID, Magazine cover or Lifestyle.
All modes support clothing presets. Custom requires a second image, used only
as an outfit reference; the first image remains the identity reference.

- Photo-ID: white, blue, red or light-gray background; centered head-and-shoulders
  composition. Choose an aspect ratio/size supported by the selected model.
  Shared visual style is ignored. Official passport/visa/ID compliance is not guaranteed.
- Magazine cover: editorial style, framing and optional cover title. Leave the
  title blank to generate no text; review any generated lettering before use.
- Lifestyle: scene, lighting, framing, pose and mood. Shared visual style is supported.

Use an image-edit-capable model. Custom outfits need a model supporting two
reference images. Cloud uploads require confirmation. Results use the host's
shared Output, run history, Gallery viewer and download actions.
Settings persist per Mini-App. Gallery references can be restored; local uploads
may need to be selected again after refreshing. Identity/outfit accuracy depends
on the model and should be reviewed.

## 中文说明

上传清晰的单人参考照，选择证件照、杂志封面或生活写真。各模式均可选择衣着；
Custom 必须提供第二张服装参考图。第一张用于人物身份，第二张仅用于衣着。

- 证件照：可选白、蓝、红、浅灰背景及模型支持的画面比例/尺寸；固定正面头肩构图，
  不应用全局视觉风格。不保证符合护照、签证或官方证件规格，请自行核对。
- 杂志封面：可选封面风格、取景及刊名。刊名留空时不生成文字；AI 文字需人工检查。
- 生活写真：可选场景、光线、取景和姿势气氛，支持全局视觉风格。

Custom 需要支持两张参考图的编辑模型。Cloud 上传前会确认；结果统一进入宿主
Output、运行历史和 Gallery。参数随草稿保存，本地上传图片刷新后可能需重新选择。
