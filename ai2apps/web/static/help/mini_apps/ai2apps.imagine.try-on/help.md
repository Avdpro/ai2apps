# Try On / 试穿试用

Provide two images: the person first, then the item. Both are required. You can
drag a generated Extract Items result directly into the item Slot.

Choose Wear, Use or Hold. Choose a pose (keep original, standing, sitting,
walking, or Custom) and background (keep original, white studio, street, park,
interior, or Custom). Custom choices require a description. Add instructions to
specify contact, placement or details to preserve.

Only models supporting at least two reference images for image editing are
listed; OpenAI models are preferred. The item image is not a person-identity
reference. Shared visual style is ignored to preserve the original appearance.
Inspect/edit the complete prompt before generating; parameter changes regenerate it.

This is an AI visualization, not evidence of actual garment sizing or fit.
Review likeness, item details, hands and contact. Results use shared Output,
Gallery and download. Parameters and Gallery references persist as drafts;
local/output-dropped files may need selecting again after refresh.

## 中文说明

第一张人物照和第二张物品参考图均必填；可将“提取物品”的 Output 直接拖到物品槽。
互动方式包括试穿/佩戴、使用、手持。姿势和背景可选预设或自定义；自定义描述必填。
补充说明可指定物品位置、手部接触、穿戴方法或要保留的细节。

仅列出支持双图编辑的模型，优先 OpenAI。物品图中的模特不作为身份参考；不应用
全局视觉风格。可检查和编辑实际 Prompt，参数变化会重新生成。结果不代表真实
尺码和合身度，请核对人物、物品、手部细节。复用共享 Output、Gallery、草稿流程。
