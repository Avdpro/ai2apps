# Image to Video

Animate a starting image, optionally guiding the final frame.

## How to use

1. Add the first-frame image and optionally a last-frame image.
2. Describe motion, camera behavior, and changes over time rather than repeating visible details.
3. Choose the model, resolution, duration, and generation settings, then run.

The first frame is required. Use images with compatible aspect ratios when supplying both endpoints.
