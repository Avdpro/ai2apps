# Audiobook

Prepare long-form narration as a project with manageable segments.

## How to use

1. Create a project, add its title and source text, and split or edit the narration segments.
2. Assign voices and delivery settings consistently.
3. Render the project, review each segment, and revise pronunciation or pacing where needed.

Long source text may be divided into segments. Keep names and uncommon words consistent for reliable pronunciation.
