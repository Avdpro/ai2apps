# Sticker Workshop / 表情包工坊

Upload one clear photo of a person or pet. Choose Happy, Love, Surprised or
Pleading, optionally choose a shared visual style, then Generate one sticker.
Generate set creates four separate image Runs sequentially, retaining the same
reference and settings. Cloud requests upload the reference and charge per image;
the set confirmation covers all four requests. Stop after current image prevents
the next request; completed images remain available in host Output and Gallery.

Results have a white background, not guaranteed alpha transparency. Identity
consistency is model-dependent. No caption text is generated in this first version.
Select an emotion and Generate again to remake only that expression. Original
results remain in history. Gallery references can be restored; local uploads may
need selecting again after reload. A refreshed page retains Runs, not an unfinished
client-side set queue. Generation requires an image-edit-capable model.
