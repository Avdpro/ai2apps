# Upscale Image / 放大图片

Enlarge one PNG, JPEG or WebP image locally using SoL. The output is a PNG at exactly twice the oriented source width and height. Transparency is preserved. Animated images and HDR/16-bit inputs are not supported. Larger images need more unified memory.

Choose an image from a local file, Gallery or another Mini-App's Output. Install a compatible model from the model menu if necessary. Standard uses SoL's built-in prompt; the custom-prompt model accepts up to 2,048 characters. Seed controls reproducibility. Results use the shared Output, with download and Add to Gallery.

使用 SoL 在本机放大单张 PNG、JPEG 或 WebP。输出为 PNG，宽高分别为按方向信息校正后的原图的两倍，并保留透明通道。不支持动画和 HDR/16 位图片；大图需要更多统一内存。

支持从本地文件、Gallery 或其他 Mini-App 的 Output 拖入图片。可通过模型菜单安装兼容模型。标准模型使用内置提示词，自定义提示词模型可输入最多 2,048 字符。随机种子用于复现结果。生成结果进入共享 Output，可下载或加入 Gallery。
