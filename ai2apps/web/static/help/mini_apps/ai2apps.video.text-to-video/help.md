# Text to Video

Create a video from a written scene description.

## How to use

1. Describe the subject, action, setting, camera movement, lighting, and visual style.
2. Choose a compatible model, resolution, duration, and optional preset, steps, seed, and label.
3. Run generation after the draft is ready.

No source asset is required. If generation is unavailable, configure a video model and check that the prompt is not empty.
