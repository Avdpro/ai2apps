# Product Photo Studio / 商品摄影棚

Upload one clear product photo or drag one from Gallery. Choose White Studio,
Stone Podium, Lifestyle Tabletop, Outdoors, Gift Setting, or Custom Scene.
Custom Scene requires a description. Choose lighting and centered/left/right
composition; left/right leave space for later typesetting, without generating copy.

Additional instructions are optional. Shared visual style is ignored by default;
enable the scene-style checkbox to apply it only to the setting. The workflow
prefers OpenAI editing models but supports compatible local image-edit models.
Cloud use requires the existing reference-upload confirmation.

The model is instructed to retain product identity, original angle, colors,
logos and label text, but this version regenerates an image. It does NOT isolate
the product with a mask or guarantee pixel-exact preservation. Inspect all details
before commercial use. No automatic advertising copy, pricing or logos are added.

Results use the shared Output, Run history, download and Add to Gallery controls.
Scene/light/composition choices persist in drafts and Run inputs. Local file
references may need reselecting after reload; Gallery references can be restored.
