# Extract Items / 提取物品

Upload a photo and select Complete outfit, Clothing, Top, Pants, Skirt, Dress,
Shoes, Bag or Custom. Custom requires a target description. Use additional
instructions to identify the person or item location when the photo is ambiguous.

The result is one white-background reference image, without the wearer or scene.
Complete outfits are arranged as separate items in a single flat-lay composition.
This is AI reconstruction, not a pixel-exact cutout; hidden parts may be inferred.
Review logos, garment patterns and geometry. Alpha transparency is not guaranteed.
Shared visual style is intentionally ignored to preserve the original appearance.

The full model prompt can be inspected and edited. Cloud uploads need confirmation.
Results use shared Output and can be dragged into another Mini-App's image Slot,
including Portrait's Custom clothing reference. No separate Package is needed.

## 中文说明

上传照片，选择整套穿着、衣服、上衣、裤子、裙子、连衣裙、鞋子或包；也可选择
自定义并输入物品描述。多个相似物品时，在补充说明中指定人物或位置。

生成独立白底物品参考图，不包含穿戴者和原场景。整套穿着在一张图里平铺排列。
这不是精确抠图：遮挡部分可能被推测补全，Logo、图案、标签和结构需要核对；
不保证透明背景。为了保持原貌，本模式不应用全局视觉风格。

可以检查和编辑完整 Prompt。结果复用 Output、Gallery 与下载，可直接拖进其他
Mini-App 的图片 Slot，例如 Portrait 的 Custom 服装参考槽。无需单独安装 Package。
