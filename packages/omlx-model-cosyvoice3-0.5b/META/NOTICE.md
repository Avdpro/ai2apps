# Notice

This Package integrates CosyVoice 3, originally developed by FunAudioLLM, and
the MLX port published by DePasqualeOrg/mlx-audio-plus.

Sources:

- https://github.com/FunAudioLLM/CosyVoice
- https://github.com/DePasqualeOrg/mlx-audio-plus
- https://huggingface.co/mlx-community/Fun-CosyVoice3-0.5B-2512-4bit
- https://huggingface.co/mlx-community/Fun-CosyVoice3-0.5B-2512-8bit
- https://huggingface.co/mlx-community/S3TokenizerV3

The S3TokenizerV3 checkpoint is an MLX conversion derived from
FunAudioLLM/Fun-CosyVoice3-0.5B-2512 and is installed as a pinned internal
checkpoint required by both CosyVoice variants.
