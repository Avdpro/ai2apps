# FlashHead MLX Package sources

Native MLX port of Soul-AILab/SoulX-FlashHead, commit 9bc03de06bb0de82cd6bc477804512ae06144bf2.
Upstream Apache-2.0 notice is preserved in LICENSE.upstream.
Wan VAE, Wav2Vec2, attention, tensor and media helpers derive from this repository’s EchoMimic V3 MLX implementation. Lite uses the upstream LTX VAE architecture.
Checkpoint revisions and preparation are recorded separately. Model weights and Runtime binaries are not Package payload.
