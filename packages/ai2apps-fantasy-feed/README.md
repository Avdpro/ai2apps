# 幻想信息流 / Fantasy Feed

在 Imagine Studio 的更多 Mini-Apps 中打开。设置聊天风格、画幅和会话开始时间，
为自己和其他参与者填写昵称并选择本地头像。最多 16 位参与者、30 条消息。
每条消息可选择发送者和内容类型，并可调整顺序。首条消息的时间差从会话开始
算起，其余从上一条消息算起。视频按独立的统一动画间隔播放。

- 图片使用本地素材。视频可以在编辑器里播放原片，聊天画面使用封面、播放图标和时长。
- 网页卡片使用填写的地址、标题、摘要和可选预览图，无需联网抓取。
- 位置卡片接受地点、地址和可选地图截图，未选地图时显示带标注的示意图。
- 名片可填写姓名、号码或账号和头像。转账和红包可设置币种、金额、备注及状态。
  微信红包的聊天卡片采用祝福语及领取状态。其他风格没有对应样式时显示为虚构卡片。
- PNG 保存预览所选节点的画面，MP4 从头播放完整对话。成品带有「虚构对话」标记，
  可在 Imagine Studio 的共享输出区预览和下载。

微信浅色群聊以用户提供的 iPhone 截图为布局参考。WhatsApp、Telegram 和
iMessage 使用各自的时间显示策略和视觉预设。分隔时间阈值是模拟参数，
不同客户端版本和地区的交易卡片可能有差异。

导出由本机 Studio 保存，需要宿主支持 `media.visual_sequence.export`。

## Bot 接入

在「参与者档案」里将自己的档案标记为「这个档案是我」。如果妈妈的档案昵称不是
「妈妈」，把「妈妈」加到 Bot 匹配别名。普通 Bot 获得此 App 的使用权限后，可以先
编写剧本，再通过 AaAT 按实际称呼匹配档案，生成 PNG 或无声 MP4。找不到或出现
重名时，先请用户确认。AaAT v1 接收文字剧本，头像从当前本机档案读取，
丰富消息仍可在编辑器里创建。

在桌面创意画坊打开「幻想信息流」，点击标题栏的快捷 Bot 按钮并选择「创建快捷 Bot」。
ASC-Bot 只保存聊天样式、画幅、状态栏、输入栏、电量和动画间隔。点击快捷 Bot 会打开
编辑器恢复这些设置，不自动生成，也不会把剧本或头像写入快捷预设。
