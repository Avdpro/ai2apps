# Sound Effects / 音效生成

Choose a model, enter a description and duration, then Generate. Use Install model to configure models through ACPF. Stable Audio requires explicit license acceptance before weights download.

Music supports ACE-Step optional lyrics (10–120 seconds) and Stable Audio instrumental generation (1–120 seconds). Sound Effects uses Stable Audio SFX (1–120 seconds). Advanced controls set steps and seed. Same seed is not a promise of identical results across different models.

Results appear only in the Host Preview & Output, shared across Mini-Apps. Cancel or closing this Mini-App cancels an unfinished generation; tasks are not durable across Local restarts. No reference audio, continuation or streaming in this version.

选择模型，填写描述和时长，点击生成。模型安装及许可确认由 ACPF 完成。结果在共享预览与输出中播放、保存；取消或关闭 Mini-App 会取消未完成的生成。
