# AVTR-1 CUDA development Package

Uses the existing pinned AVTR composite checkpoint under its original community and component terms. LICENSE files, ATTRIBUTION and the exact download-consent/redistribution contract are preserved. No installer license declaration is preaccepted or inherited.

This Package supplies the CUDA Worker adapter; pinned engine, decoder and media implementations belong to the CUDA Runtime. Standard and fast request modes retain their distinct decoder choices. Fixed converted graph assets do not imply that Mac precision or throughput applies to CUDA.

Draft Package source. Its fixed checkpoint distribution is published and verified in signed Index134; shared Runtime GPU regression and signed installation are still required. The current adapter fixes top-level Host preset/duration handling with nested parameters; prior GPU records do not verify this new Package.

`META/vendored-sources.json` retains original Mac conversion/helper provenance hashes for attribution. Those files are not vendored in this adapter-only Package; the Runtime maintains its own executable source inventory.
