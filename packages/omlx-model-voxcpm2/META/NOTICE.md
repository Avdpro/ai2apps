# Notices

This Package integrates VoxCPM2 from OpenBMB and MLX conversion support from
MLX-Audio. VoxCPM2 code and model weights are distributed under Apache-2.0.

- Upstream: https://github.com/OpenBMB/VoxCPM
- Model: https://huggingface.co/openbmb/VoxCPM2
- MLX implementation: https://github.com/Blaizzy/mlx-audio

The AI2Apps adapter adds capability validation, offline checkpoint selection,
and unified speech-control mapping.
