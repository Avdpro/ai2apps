# VoxCPM2 2B

AI2Apps Model Worker Package for native MLX VoxCPM2 synthesis on Apple
Silicon.  It provides transcript-free reference voice cloning, voice design,
and natural-language expression control with 48 kHz native output.

The public `speed` field is mapped to qualitative model instructions.  It is
not advertised as exact duration control.  A saved reference transcript is
accepted for compatibility but is not used by controlled reference cloning.
