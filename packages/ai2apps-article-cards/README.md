# 文章卡片

安装本 Package 后，在 Imagine Studio 或 Doc Studio 选择「文章卡片」，粘贴正文，选 3:4（960 × 1280）或
9:16（720 × 1280），然后点击自动分页。分页使用实际字宽和文字区高度，
优先在段落之间换页。逐页可以修改正文、替换或关闭贴纸，在光标处拆页，
或与下一页合并。自动贴纸按当前页的关键词选择，可手动覆盖。

模板自带三种配色。自定义时可上传 PNG、JPEG 或 WebP 底图。默认的整页模式保留图片比例，
在不同画幅下居中裁切。需要跨画幅保留边框时，选用九宫格模式，
并分别设置四条切线，保留四个角的比例，让中间及边缘延伸到目标画幅。
「预览九宫格和文字区」可用于调整切线和边距，辅助线不会导出。
页码和表情的位置用页面百分比指定。模板可保存在当前 Studio 的模板库，
最多五个，以同名保存可更新现有模板。

单页 PNG 和包含顺序编号 PNG 的 ZIP 都保存到发起导出的 Studio 的统一 Output，
需宿主支持 `media.visual_sequence.export` 的 ZIP 输出。本地分页和渲染不使用模型。
单次最多 30 页，导出请求上限 8 MiB。可下载图片包用于手动发帖。

## 封面
可沿用选定的九宫格模板，以大字号排印封面标题。AI 模式可填写标题、
画面风格、选择生图模型和参考图。模型生成封面画面，编辑器叠加可修改的标题。
可单独导出封面 PNG，也可随正文 ZIP 导出。封面始终排在第一张，正文页码从 01 开始。
启用封面后，30 张上限包含封面。AI 模式要求宿主支持可选的 `image.workflow`，
且当前账户有就绪的生图模型。

## AI 模板底图
在「编辑模板 → AI 生成底图」中可直接按当前模板配色生成，也可补充风格。
整页模式按当前画幅生成。九宫格模式使用正方形图，默认四边各切 25%，
生成后可在辅助线下检查并微调。生成结果自动预览，可恢复上一张底图，
满意后保存为模板。先前保存的底图继续按九宫格加载。
