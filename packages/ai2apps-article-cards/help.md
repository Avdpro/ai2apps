# Article Cards / 文章卡片

Paste an article, choose an aspect ratio and template, then paginate. You can edit individual pages and export to the Studio's Preview & Output panel.

粘贴文章，选择画幅和模板后分页。可以逐页编辑，导出的文件显示在工作室的「预览与输出」。

In Doc Studio, Mini-Chat can edit the current draft. The Article Cards export tool creates a new automatic layout using a built-in template. Use the editor buttons to export manually edited pages.

在 Doc Studio 中，Mini-Chat 可以修改当前草稿。文章卡片工具使用内置模板自动排版。逐页编辑后，请使用编辑器里的导出按钮。
