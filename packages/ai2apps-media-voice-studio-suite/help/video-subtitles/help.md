# 视频字幕与翻译

选择视频和原始语言后，先点击“提取字幕段落”。Mini-App 会列出带时间范围的字幕段落；可以逐段
修改识别文本，也可以清空某段文本来移除该段字幕。完成校对后，再选择可选目标语言、字幕格式和
烧录样式。处理链路下方的“生成字幕文件”只导出 SRT、WebVTT 或 ASS；独立的
“生成字幕视频”会把当前校对文本直接烧录到新视频。

当前 MVP 已接通完整 Host 流程。未选择翻译时只需要本地详细转写模型；选择翻译时会在校对之后
使用当前配置的 Standard 模型。导出 ZIP 始终包含字幕文件和校对后的转写 JSON；点击
“生成字幕视频”时还包含重新编码的视频，并把最终视频交给 Video Studio 共用的 Preview & Output。
