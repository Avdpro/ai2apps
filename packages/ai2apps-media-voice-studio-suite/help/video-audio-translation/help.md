# 视频音轨翻译

这个 Mini-App 面向单讲解者、旁白类视频。它会转写并翻译原始人声，可使用 Voice Studio → Characters 中已经预览验证的 Character，或从原视频自动选取约 10 秒清晰语音、临时克隆原始音色来合成目标语言语音，同时保留从原视频分离出的音乐和环境背景。临时音色只用于本次任务，不会保存到 Characters。

当前 MVP 不区分多个说话人，也不保留原始对白。多人对话、精确口型匹配和逐句人工改稿不在当前范围内。

使用 Character 模式前，请先在 Voice Studio 的 Characters 中准备并验证目标角色。使用“原始音色”时，请在出现的模型菜单中选择一个已就绪的语音克隆模型；也可以选择“安装更多模型…”并通过 ACPF 配置。若转写或音轨分离模型尚未配置，可使用页面上的“安装并配置模型”入口完成本机模型配置。
