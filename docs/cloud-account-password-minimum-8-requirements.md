# Cloud 账户密码最小长度 8 位变更要求

日期：2026-09-03

## 目标

将 AI2Apps Cloud 账户密码的最小长度从 12 个 UTF-8 字节统一调整为 8 个 UTF-8 字节，并保证新建的 8 字节密码
账户能够完成完整账户生命周期操作。

## 必须覆盖的入口

- 注册与登录；
- 设置新密码和重置密码；
- 管理员二次验证；
- 设备撤销、组织策略、成员角色与额度等需要再次输入所有者密码的操作；
- Cloud pairing、node grant、owner link 及其他验证现有账户密码的接口。

所有入口应接受 8 字节密码并拒绝 7 字节密码。最大长度保持 128 字节；若 Cloud 当前存在更严格
且独立于长度的密码质量检查，应保留并在回执中说明。

## 不在变更范围内

- 密码哈希、盐值、密钥管理和数据库存储；
- 登录、注册、验证码和密码重置的速率限制；
- 邮箱验证、设备绑定、权限与 step-up 有效期；
- 泄露密码检测或其他与长度无关的安全策略。

## 合同与验收

- 更新服务端请求模型、领域校验、OpenAPI schema、稳定错误详情和用户文案；
- 增加 7 字节拒绝、8 字节接受、既有 12 字节以上密码继续工作的测试，并覆盖非 ASCII
  密码以确认前端与服务端都按 UTF-8 字节计算；
- 回归注册、登录、重置密码和全部再认证入口；
- 明确是否有数据库迁移（预期无）及客户端所需版本；
- 未经用户另行授权，不部署生产。
