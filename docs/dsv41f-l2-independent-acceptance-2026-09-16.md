# DS4.1F L2 独立验收（2026-09-16）

冻结候选 `block6-zero-credit-group2-startup` 在全部24个独立新会话上及时覆盖 **70.3071%** 的原始cache miss，达到本轮“独立会话、有限预算、覆盖至少70%并报告误读”的观测验收目标。这个结果不代表所有会话都超过70%，也不代表未来分布的覆盖率下界超过70%。按12个主题聚类bootstrap的95%区间为 **69.8120%–70.8503%**；余量很小。

## 数据与隔离

- 最终候选在打开预留测试集之前冻结；源码快照、基础模型源码和样本SHA在运行前核验，验收期间没有调参、删样本或选择性重跑。
- 24条人工编写的新对话历史，12主题×中英文，主题与训练/验证隔离。每条历史之后生成一段回答，并非在线连续生成多个新轮次，也不是私人真实用户日志。
- 最大256 decode，启用EOS停止。本批所有样本均达到256上限，共6144 token；没有因EOS停止而缩短的样本，因此不宣称已覆盖这类行为。
- 全部40层、全Top6原始实际miss作分母。timely只计原miss安全栅栏之后、前台读取入口时已经READY的数据；late另列。
- 训练扩充语料130序列/21632行（训练104/17152，验证26/4480）。最终独立会话不用于任何训练或选择；这批测试集现在已消费，未来调参不能再把它当作新的独立验收。

TPS包含模型入口到collection完成、预测开销、预取收尾和诊断复制。每会话剔除prefill及前4个decode后，按总计时token/总秒数池化（两路径各6048 token），并非平均各会话TPS。严格F_NOCACHE，读取使用原native preadv SSD加载器。该计时属于带诊断的隔离实验，不可直接对比历史不同提示的7.x TPS，也不是10 TPS目标的完成证明。

单会话及时覆盖范围66.677%–74.863%；23/24会话TPS高于配对基线，一条约下降1.7%。每种路径只跑一遍，因此不能把微小单例差异认定为稳定提升或回退。总量SSD读取增加，减少的是前台阻塞miss，不是物理读取总量。

## 可执行方案与边界

逻辑缓存保持L0=8、L1=40、`eviction_dual`，主前向不启用Burst，始终精确Top6。每层额外8个物理暂存槽，总320槽，payload约6.016GB；每token最多64次实际预取，取消且尚未执行的请求可回收预算。物理槽归属交换消费READY专家，不复制整块专家数据。

预测按6层短块执行：从当前精确hidden/KV状态出发，只用已驻留专家做近似前向，冷专家贡献置零，产生官方router分数；随后恢复状态执行精确主前向。连续2层预测共用一次异步通知。合并原cache-hit与miss metadata回读，以节省的回读次数抵付通知；首层预测路由与真实路由相同，可复用该通知替代首层hit标量回读。测试逐token检查通知＋路由回读不超过基线，并逐token确认首层路由一致。原bank安全栅栏保留；这不是全进程所有诊断传输的硬件级GPU事件统计。

所有生成IDs、完整logits SHA、真实路由、逻辑resident membership与cache_stats均与对应基线一致。审计重新检查L0/L1、无Burst、内存、每token读取预算和路由通知计数。源码检查确认预测不读取未来真实路由标签。

此方案不是已训练好的小矩阵：训练后的全状态r512验证覆盖约38.80%，lookahead per-layer-r64约56.84%（离线无截止时间），尚不足以替代当前近似前向。有效结果来自实际执行并验证的驻留专家预测路径。实验入口使用legacy逐层主路径，尚未接入生产miss-resume Runtime、模型Package或视觉路径；不把本报告当作这些组合的发布验收。
