# DynaMoe

DynaMoe는 Apple Silicon을 위한 독립적인 동적 MoE 추론 프로젝트이며,
오픈 소스 [oMLX](https://github.com/jundot/omlx) 런타임을 기반으로 합니다.

DynaMoe는 oMLX 프로젝트 또는 유지관리자와 제휴, 후원, 인증 또는 보증 관계가
없습니다. oMLX라는 이름은 런타임의 출처를 밝히기 위해서만 사용합니다.

자세한 내용은 [기본 README](README.md), [아키텍처](docs/architecture.md),
[NOTICE](NOTICE)를 참고하십시오. 이 프로젝트는 [Apache-2.0](LICENSE)으로
배포됩니다.
